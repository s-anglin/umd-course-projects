# UMD Academic Projects

This repository contains selected academic projects completed during my time at the University of Maryland. These projects demonstrate experience in database design, data analysis, machine learning, and applied research, with a focus on real-world datasets and healthcare applications.

## Projects

### Chicago Traffic Citations Management Database
Designed and implemented a relational database using SQL and MySQL to analyze traffic citation data. The project involved normalizing data to Third Normal Form (3NF), creating an Entity-Relationship Diagram (ERD), and developing stored procedures, views, and functions to support analytical queries on citation trends, officer activity, and fine distributions.

**Skills & Tools:** SQL, MySQL, Database Design, Data Normalization, ERD Design

---

### Stroke Prediction Model
Built and evaluated machine learning models in R to predict stroke outcomes using a healthcare dataset. This project included data preprocessing, feature engineering, handling class imbalance using SMOTE, and evaluating model performance using ROC curves, sensitivity, specificity, and fairness metrics. Bias analysis was conducted to identify and mitigate disparities in model outcomes.

**Skills & Tools:** R, Machine Learning, Feature Engineering, Model Evaluation, Fairness & Bias Analysis

---

### Technology in Healthcare Review Article
Authored a research review examining the impact of Artificial Intelligence (AI) and the Internet of Things (IoT) in healthcare. The paper synthesized over 20 scholarly sources to evaluate improvements in diagnostics, patient monitoring, and hospital efficiency, while also addressing ethical, privacy, and security considerations.

**Skills & Tools:** Academic Research, Technical Writing, Literature Review, Critical Analysis
